# 🖱️ ClickerGameTS

A high-performance, standalone 3D incremental desktop clicker game built using **TypeScript**, **Three.js**, and stylized with an ultra-responsive utility grid. The application leverages a native desktop window environment powered by **Electron** and **electron-builder**.

## ✨ Features

* **Secure Cheat Validation**: Implements a client-side cryptographic bypass layer utilizing obfuscated Base64 hash evaluations to prevent casual string sniffing in DevTools.
* **Type-Safe Calculations**: Full TypeScript type assertions (`as HTMLButtonElement | null`) governing all upgrade parameters and shop cost scaling algorithms.
* **Exponential Economy Math**: Upgrade costs automatically scale exponentially (+35% for Super Clickers, +40% for Auto-Clickers) with every purchase.
* **Cross-Tab State Mirroring**: Implements a dedicated window storage event architecture ensuring instant realtime session synchronization.
* **Classic Glass Title Shells**: Completely strips standard Chromium drop-down menus via desktop initialization hooks (`.setMenu(null)`) for an immersive interface.
